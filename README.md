# 🏡 Real Estate Portal

A web-based Real Estate Management System developed using Java, Spring Boot, JSP, and MySQL. The application provides a platform for managing property listings, seller accounts, buyer inquiries, and administrative activities.

## 🎓 Academic Context

- **University:** Sri Lanka Institute of Information Technology (SLIIT)
- **Faculty:** Faculty of Computing
- **Project Type:** Academic Group Web Application
- **My Role:** Seller Module Developer

## 🚀 Features

- User registration and login
- Property listing and management
- Seller registration and profile management
- Seller dashboard
- Property image uploads
- Property information and pricing management
- Buyer inquiries
- Administrative management
- Property reviews

## 👨‍💻 My Contribution — Seller Module

As part of the group development team, I was responsible for developing the Seller Module.

### Key Responsibilities

- Developed seller registration and login functionality.
- Implemented seller dashboard features.
- Developed property listing creation, editing, and deletion functionality.
- Integrated property image uploads.
- Implemented property details and pricing management.
- Developed functionality to view buyer inquiries.
- Worked with MySQL for database-related operations.

This module provided practical experience in Java web application development, database operations, CRUD functionality, and collaborative software development.

## 🛠️ Technologies Used

- **Backend:** Java 17, Spring Boot 3.2.0, Jakarta Servlets
- **Frontend:** JSP, HTML, CSS, JavaScript
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **Build Tool:** Maven
- **Version Control:** Git and GitHub

## 📋 Prerequisites

- Java JDK 17 or higher
- Maven
- MySQL Server
- A compatible development environment
